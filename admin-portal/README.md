# Admin Portal — Traffic Fine Payment System

Admin dashboard for managing traffic fine payments, officer accounts, and generating reports.

## Features

- **Dashboard** — Summary statistics (total fines, paid, pending, revenue)
- **Payments** — View payment records and transaction history
- **Reports** — Monthly analytics and revenue reports
- **Officers** — Manage police officer accounts and permissions

## Setup

```bash
npm install
npm run dev
```

Admin portal runs on `http://localhost:3002` (or next available port).

## Integration

Connects to backend API on `http://localhost:3001` for data retrieval.
